### Known C++ Adaptations (Documented)
- encode()/decode() are no-ops (std::string is byte-based)
- isdecimal()/isnumeric() use isdigit() (C++ limitation)
- split() family returns flattened arrays (not object arrays)
- translate() uses 256-char table (not dict-based)

All documented in char.hpp file header.

## Migration Guide

Users should use free functions instead of chararray:

```cpp
// ✅ Modern approach (recommended)
auto data = array(std::vector<std::string>{"hello", "world"});
auto result = capitalize(lower(strip(data)));

// ❌ Deprecated approach (still works but shows warning)
chararray ca(data);
auto result = ca.strip().lower().capitalize();
```
